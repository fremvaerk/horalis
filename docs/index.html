The floating timer - always visible, never in the way

Everything you need, nothing you don't

Built for developers who want to track time without the overhead of complex tools.

Floating Timer

Always-on-top minimal window that stays with you across workspaces. Small, unobtrusive, always accessible.

Project Tracking

Organize time by project with custom colors. Quick-switch between projects from the floating timer or system tray.

Smart Idle Detection

Auto-pause when you step away from the keyboard. Configurable timeout so you never lose track of actual work time.

Visual Reports

Weekly and monthly charts show where your time goes. See patterns, identify focus areas, understand your work habits.

Gentle Reminders

Configurable notifications when you forget to start tracking. Set time windows so they only appear during work hours.

Privacy First

All data stays local in an SQLite database on your device. No accounts, no cloud sync, no tracking. Your time data is yours alone.

Built with modern tools
